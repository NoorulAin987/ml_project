# Streamlit Credit Card Fraud Detection Application

This project is a Streamlit application designed for credit card fraud detection using machine learning techniques. The application provides an interactive interface for users to explore the dataset, visualize class imbalances, and make predictions on new transactions.

## Project Structure

```
streamlit-app
├── src
│   ├── app.py                # Main entry point of the Streamlit application
│   ├── components            # Reusable components for the app
│   │   └── __init__.py
│   ├── pages                 # Different pages for the multi-page app
│   │   └── __init__.py
│   └── utils                 # Utility functions for data processing
│       └── __init__.py
├── requirements.txt          # Project dependencies
├── .streamlit
│   ├── config.toml          # Streamlit configuration settings
│   └── secrets.toml         # Secure storage for sensitive information
└── README.md                 # Project documentation
```

## Setup Instructions

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd streamlit-app
   ```

2. **Install dependencies:**
   Make sure you have Python installed, then run:
   ```
   pip install -r requirements.txt
   ```

3. **Run the application:**
   Start the Streamlit app with the following command:
   ```
   streamlit run src/app.py
   ```

## Usage Guidelines

- Navigate through the different pages of the application to explore the dataset and visualizations.
- Use the provided components to input transaction data for fraud detection.
- Review the results and insights generated by the machine learning models.
